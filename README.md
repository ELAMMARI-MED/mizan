# المِيزان — أداة لتقطيع الشعر العربي

تطبيق ويب عربي (RTL) لتقطيع الشعر العربي عموديًّا: يُدخل المستخدم بيتًا مشكَّلًا فيعيد المحرك البحرَ،
والتفعيلات، والزحافات، والقافية — مع شرح سبب الخلل إن لم يطابق الوزن.

- الواجهة: HTML/CSS/JS بلا أي إطار عمل، وضع نهاري وليلي، خطوط عربية محليّة، عمل دون شبكة (Service Worker).
- المحرك: [pyarud](https://pypi.org/project/pyarud/) (رخصة MIT) — قواعد الخليل بن أحمد.
- التغليف: تطبيق أندرويد (Chaquopy) يعمل بلا إنترنت: المحرك مضمَّن داخل الـ APK.

## التشغيل على الحاسوب/Termux

```bash
python3 -m pip install pyarud
python3 server.py          # http://localhost:8096
```

## ما تفتحه الأداة

| العنصر | التفصيل |
| --- | --- |
| البحر | الطويل، المديد، البسيط… (الستة عشر) مع نوعه: تام / مجزوء |
| التفعيلات | لكل شطر، مع اسم التفعيلة كما وردت (سالمة أو مزحوفة) |
| الزحاف | زرّ لكل زحاف يشرحه (الخبن، القبض، الطي…) |
| الرموز | `1` للحركة و`0` للسكون، وتُقرأ **من اليمين إلى اليسار** |
| لماذا لم يطابق | أول تفعيلة خالفت الوزن: المتوقَّع مقابل الموجود + أقرب البحور |
| القافية | الرويّ وحركته والتأسيس والدخيل والرِّدف |
| عيوب القافية | الإيطاء، السِّناد، التوجيه، واختلاف البحر بين الأبيات |
| التشكيل | كشف الكلمات بلا حركات لأن الوزن يُقارَن بالنطق |
| التدريب | بيت عشوائي وأربعة اختيارات، والمحرك هو الحكم |
| السجل | آخر عشرة تحليلات، مع نسخ النتيجة وطباعتها |

## الاختبارات

```bash
python3 test/golden.py -v     # بيت واحد لكل بحر من الستة عشر عبر المحرك
node test/ui.cjs              # 27 تحقّقًا للواجهة على الخادم الحيّ (jsdom)
```

`test/ui.cjs` يحتاج الخادم على `http://127.0.0.1:8096` و`jsdom` (مثال:
`npm i jsdom` ثم `MIZAN_BASE=... node test/ui.cjs`).

## بنية المشروع

```
mizan/
├── index.html            الواجهة (خمس شاشات: التقطيع · تدريب · البحور · مصطلحات · عن الأداة)
├── app.js                الحالة والعرض والتدريب والسجل
├── styles.css            الهوية البصرية + الوضعان النهاري والليلي
├── sw.js                 Service Worker: الشبكة أوّلًا، والكاش عند الانقطاع
├── fonts/                Amiri + Reem Kufi محليًّا (لا اتصال بجوجل)
├── prosody_core.py       نواة العروض المشتركة بين الخادم والتطبيق
├── server.py             خادم التطوير — المنفذ 8096
└── test/                 golden.py (البحور) · ui.cjs (الواجهة)
```

`prosody_core.py` هو المصدر الوحيد للمنطق: `server.py` للتطوير و`app_server.py` داخل الـ APK
يستوردان نفس الملف، فلا تتباعد نسختان.

## بناء APK

```bash
cd ~/mizan-android && bash build-apk.sh 1.1.0
```

ينسخ الواجهة والنواة، يبني `assembleRelease` بـ Gradle، يوقّع، وينسخ الناتج إلى
`~/storage/downloads/Mizan.apk`.

## ملاحظات

- النص **لا بد** أن يكون مشكَّلًا: الوزن يقوم على النطق لا على الرسم.
- المحرك يعمل محليًّا بالكامل: لا إرسال لأي نص إلى خدمة خارجية.
- للمِيزان نسخة أندرويد (تطبيق مستقل) تعمل دون إنترنت.
